Maintenance

Setup wizard

Restart the initial setup wizard (profile, security, MQTT). The current configuration is unchanged until the wizard is submitted.

Firmware update

Running from the SD card: upload a tc100-update-<version>.tar package (built by src/release/build-update.sh). It is checked file by file before anything is installed; only changed files are replaced, the previous ones are kept for a rollback, and the camera reboots at the end. Your settings, start-at-boot choices and Wi-Fi credentials are kept. Running from the flash memory (FLASH badge): upload a tc100-code-<version>.bin package (src/flash/build-code.sh); it is written to the flash, read back, and the camera reboots; "Roll back" returns to the code built into the firmware.

From the flash memory, a system package tc100-system-<version>.tar (made by src/flash/build-flash-kit.sh) also replaces the programs, without SD card.

Installed version: …

Install to flash (run without the SD card)

Puts this firmware into the camera's own memory, so that it works without the SD card (README, "Install to flash"). Three steps: 1. the camera copies its original system partition to the card (nothing is written to the flash); 2. on a computer, src/flash/build-flash-kit.sh turns that copy into the image to install; 3. card back in, the camera installs it at boot, checks it, and restarts from its flash. The card keeps working as before until step 3 succeeds.
