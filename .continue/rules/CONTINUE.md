## 5. Key Concepts

### Domain-Specific Terminology
- **RTSP (Real Time Streaming Protocol):** Protocol for controlling streaming media (video/audio)
- **ONVIF (Open Network Video Interface Forum):** Standard for IP video devices (profiles, events, PTZ)
- **Motion Detection:** Algorithm to detect movement in video frames
- **Sound Detection:** Algorithm to detect specific sound patterns (e.g., alerts)
- **Time-Lapse:** Recording at a low frame rate to compress time
- **IR-Cut:** Mechanical filter to block infrared light (day/night mode)
- **Watchdog:** Service that monitors and restarts other services on failure
- **Root FS (Root File System):** The complete filesystem image for the embedded device

### Core Abstractions
- **Service Manager:** `controlscripts/` contains start/stop/status scripts for each service
- **Configuration Layer:** `config/` provides a centralized configuration interface
- **Event Pipeline:** Detection events are processed and forwarded to integrations (MQTT, Telegram, etc.)
- **Storage Manager:** Handles recording, cleanup, and integrity checks

### Design Patterns
- **Service Pattern:** Each service (web, RTSP, detection, etc.) is managed independently via `controlscripts/`
- **Observer Pattern:** Detection events trigger notifications (MQTT, Telegram, SMTP)
- **Template Method:** Configuration files (`.dist`) provide defaults, overridden by active configs
- **Facade Pattern:** Web interface (CGI scripts) provides a unified API for system management

## 7. Troubleshooting

### Common Issues

| Issue | Possible Cause | Solution |
|-------|---------------|----------|
| Web interface inaccessible | lighttpd not running, network issue | Check service status: `sh controlscripts/web-server/web-server status` |
| No RTSP stream | v4l2rtspserver not running, codec issue | Check service status: `sh controlscripts/rtsp-h26x/rtsp-h26x status` |
| Motion detection not working | Threshold too high, sensor issue | Adjust threshold in `config/motion.conf.dist`, check camera |
| Alerts not received | MQTT/Telegram/SMTP misconfigured | Test connections: `sh scripts/mqtt-bridge.sh`, `sh scripts/sendMailTest.sh` |
| Recording not working | Storage full, codec issue | Check storage: `sh scripts/storage-cleanup.sh`, check logs |
| Device rebooting | Watchdog triggered, memory leak | Check logs: `http://<camera-ip>/logs.html`, monitor RAM usage |

### Debugging Tips
1. **Enable verbose logging:**
   ```bash
   export LOG_LEVEL=debug
   sh scripts/common_functions.sh
   ```
2. **Check service status:**
   ```bash
   for service in controlscripts/*; do
     echo "=== $service ==="
     sh "$service" status
   done
   ```
3. **Monitor system resources:**
   ```bash
   watch -n 1 'free; df -h; top -b -n 1'
   ```
4. **Check network connectivity:**
   ```bash
   ping 8.8.8.8
   curl -I http://<camera-ip>/
   ```
5. **Review logs:**
   - `/var/log/syslog` (if available)
   - `http://<camera-ip>/logs.html`
   - `sh scripts/event-logger.sh` (for detection events)
