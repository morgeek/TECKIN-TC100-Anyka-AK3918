## Encoder access (steps toward H.264/H.265 on 6.6)
- `drivers/misc/ak39_venc.c` registers a misc device named `uio0`: maps the Allegro DVT window (0x20020000, 64 KiB, IRQ 2), waits for the IRQ, resets/gates the encoder (SYSCTRL 0x1C / 0x20 bit 18), exports a reserved 12 MiB DMA pool (0x81800000, DT `venc_pool`).
- ioctls (include/uapi/linux/ak39_venc.h): SYSREG_WRITE 'U',100; WAIT_IRQ 'U',101; VIDEO_RESET 'U',105; POOL_INFO 'U',110. mmap offsets: regs 0, pool 0x10000000.
- `src/libakuio/`: free drop-in for the vendor libakuio.so (the 7 functions imported by libmpi_venc, libplat_vi, libplat_venc_cb, libmpi_osd), sub-allocating the pool in 32-byte units. Allocator self-test passes on the host.
- Memory layout (RAM test boot): initrd 0x81000000, venc pool 0x81800000-0x82400000, CMA 28 MB at 0x82400000.
