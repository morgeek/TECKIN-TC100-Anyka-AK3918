# Day / night measured on two cameras, night of 2026-11-11 to 12 (times UTC; Paris = UTC+1)

Both cameras indoors, same firmware family (.24 on 3.0.0, .11 on 3.0.1-rc37), default thresholds (no VENDOR_* or
AWB_* line in daynight.conf: VENDOR_NIGHT_LUM 3584, VENDOR_DAY_LUM 1536, AWB_DAY_CNT 50000, MIN_SWITCH 180 s). Log line
every 5 min (`mode src luma ae ... lum awb[10] ... u v`), plus a 5 s capture of luma / AE / IR-cut on the .24.
`lum` = stock luminance (exposure x gains / AE luminance: higher = darker), `awb` = first white-balance count.
